# Explainable AI Car Valuation System

An AI-powered web application designed to estimate used car prices using Machine Learning and explain the factors influencing each prediction using Explainable AI (XAI).

## Project Overview

The Explainable AI Car Valuation System helps users estimate the value of a used car based on vehicle information such as brand, model, year, mileage, engine size, condition, and other features.

The system uses an **Extra Trees Regressor** for price prediction and **SHAP (SHapley Additive exPlanations)** to provide understandable explanations of the factors that influence each predicted price.

## Key Features

 AI-based used car price prediction
 SHAP-based explainable AI
 Predicted price in USD
 🇱🇰 USD to LKR price conversion
 User registration and login
 User prediction history
 Downloadable prediction report
 Responsive web interface

##  Machine Learning Model

The system compares multiple regression models including:

 Random Forest Regressor
 Gradient Boosting Regressor
-Extra Trees Regressor

The Extra Trees Regressor was selected for the final system based primarily on its MAE performance.

### Model Evaluation

| Model | MAE (USD) | RMSE (USD) | R² |
|---|---:|---:|---:|
| Random Forest | 1875.82 | 3354.17 | 0.8792 |
| Gradient Boosting | 1893.93 | 3390.54 | 0.8766 |
| Extra Trees | 1839.58 | 3373.83 | 0.8778 |

##  Explainable AI

SHAP is used to explain individual predictions. Instead of only displaying a predicted price, the system shows which vehicle characteristics increased or reduced the model's estimated value.

Example factors include:

- Vehicle year
- Mileage
- Vehicle condition
- Engine size
- Brand and model
- Ownership history
