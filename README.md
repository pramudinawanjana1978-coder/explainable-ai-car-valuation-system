# 🚗 Explainable AI Car Valuation System

An AI-powered web application designed to estimate used car prices using Machine Learning and explain the factors influencing each prediction using Explainable AI (XAI).

## 📌 Project Overview

The Explainable AI Car Valuation System helps users estimate the value of a used car based on vehicle information such as brand, model, year, mileage, engine size, condition, and other vehicle characteristics.

The system uses an **Extra Trees Regressor** for price prediction and **SHAP (SHapley Additive exPlanations)** to provide understandable explanations of the factors that influence each predicted price.

## ✨ Key Features

-  AI-based used car price prediction
-  SHAP-based Explainable AI
-  Predicted car value in USD
-  User registration and login
-  Personal prediction history
-  Downloadable valuation report
-  Responsive React web interface
-  Deployed full-stack application

## 🤖 Machine Learning Model

Multiple regression algorithms were evaluated during model development:

- Random Forest Regressor
- Gradient Boosting Regressor
- Extra Trees Regressor

The **Extra Trees Regressor** was selected for the final system based on its prediction performance.

After removing the City feature and retraining the model, the final Extra Trees model achieved improved performance.

### Final Model Evaluation

| Metric | Result |
|---|---:|
| MAE | $1,725.87 |
| RMSE | $3,050.97 |
| R² | 0.9001 |

The R² score indicates that the model explains approximately **90% of the variation in used-car prices within the test data**.

> Note: R² is a regression evaluation metric and should not be interpreted as classification accuracy.

## 🔍 Explainable AI

SHAP is used to explain individual predictions.

Instead of only displaying a predicted price, the system also shows which vehicle characteristics increased or reduced the model's estimated value.

Example factors include:

- Vehicle year
- Mileage
- Vehicle condition
- Engine size
- Brand and model
- Ownership history
- Service history
- Accident history

This makes the machine learning predictions more transparent and understandable to users.

## 📥 Model Inputs

The final prediction model uses **12 input features**:

- Brand
- Model
- Year
- Mileage
- Engine Size
- Fuel Type
- Transmission
- Owner Count
- Condition
- Service History
- Accident History
- Features Count

The City feature was excluded from the final model to avoid location-specific information that was not appropriate for a general car valuation system.

## 📊 Prediction Output

The system provides:

- Estimated car value in USD
- Top factors influencing the prediction
- Whether each factor increased or reduced the estimated value
- Vehicle information summary
- Downloadable valuation report
- Saved prediction history for registered users

## ⚠️ Disclaimer

The predicted price is an estimate generated by a machine learning model based on patterns learned from the available dataset.

It should not be considered an exact real-world market valuation. Actual vehicle prices may vary depending on current market conditions, location, demand, taxes, vehicle-specific factors, and other information not represented in the training dataset.
